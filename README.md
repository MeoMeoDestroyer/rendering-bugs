# Rendering Bugs Without Errors — start

The Shelf, with five rendering bugs in it. None of them crashes or prints
anything in the console: each one draws the wrong thing. The lab page walks
through them one at a time — predict what the code will draw, look, fix it,
and say why.

## Run it

```bash
npm install
npm run dev
```

Open the address Vite prints, and open the browser's console (F12) beside it.
No API or other server is needed.

## What to do

Work through the lab page one section at a time, from the top. The sections
depend on each other, so do them in the order given.

The `solution` project has all five fixed.
